# 🎮 Video Game Sales Dashboard (Tableau)

An interactive Tableau dashboard analyzing global video game sales by **platform, genre, publisher, year, and region**.  

👉 [View Interactive Dashboard on Tableau Public](https://public.tableau.com/app/profile/prem.narwani/viz/VideoGameSalesDashboard_17589714423060/Dashboard1?publish=yes)

[![Dashboard Preview](images/vgsales.png)](https://public.tableau.com/app/profile/prem.narwani/viz/VideoGameSalesDashboard_17589714423060/Dashboard1?publish=yes)

---

## 📊 Highlights
- KPIs: Total Sales, Top Platform, Top Genre  
- Regional sales trends and heatmaps  
- Publisher & title rankings  
- Interactive filters (Year, Platform, Genre)
